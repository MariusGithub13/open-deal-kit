# Security

The kit is prompts and skill files; nothing here runs on its own or sends anything anywhere. Two things do
act: the example in `examples/typed-refusal-gate/` downloads four public PDFs from `os.devaland.com` and
installs a third-party package from a pinned commit, and anything you paste into a prompt goes wherever that
chat goes, so keep deal documents out of the issues here.

To report a security problem, write to office@devaland.com with the file, the commit and a way to reproduce
it. Please do not open a public issue for it. A person answers; there is no bug bounty.
